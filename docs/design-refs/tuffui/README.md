# TUFFUI reference sources

These are reference copies of TUFFUI screens and components (https://tuffui.com, https://github.com/yurigdesigner/tuffui), shared by the sponsor on 2026-11-06.

**Status:** reference only. Nothing here is imported until the v9 platform upgrade (React 19 and Tailwind v4, `docs/DESIGN-V9-TUFFUI.md`). At that point components are installed through the shadcn CLI at a pinned commit and re-themed to Mantu brand.

# Plan 012: Source hardening

The candidate route sits next to review and uses the same id parser and the same `canDoInView` gate (`review` or `approve_release` on the target). `configure` is not a content right. The brain bound wraps one brain at a time inside `cardsOf`, aborts that read at 2,500 ms, and clears the timer when the read wins. Health drops two fields. The repro script resolves the directory and `worker/entry.js` and refuses anything outside the repo root.

## Security & data

A stranger cannot tell a missing candidate from one they may not read. The health body no longer names the environment. The repro script does not import an arbitrary file. No live token or cookie is written.
